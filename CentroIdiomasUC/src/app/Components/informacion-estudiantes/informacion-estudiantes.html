Conoce los horarios flexibles, el sencillo proceso de matrícula, los requisitos y todos los beneficios exclusivos para alcanzar el dominio de un nuevo idioma.

Paso a Paso

Proceso de Matrícula 100% Simplificado

1
Elección o Test de Ubicación

Elige tu idioma desde nivel Básico 1 o rinde nuestra prueba de nivelación gratuita para validar tu nivel actual.

2
Registro de Datos

Ingresa tus datos personales en el formulario web del Centro de Idiomas y selecciona tu turno y modalidad de preferencia.

3
Pago de Matrícula / Cuota

Realiza el abono de manera segura mediante Banca por Internet (BCP, BBVA, Interbank), agente o tesorería institucional UC.

4
Activación de Aula Virtual

Recibe tus accesos a Microsoft Teams / Canvas UC, material digital de estudio y la bienvenida de tu docente asignado.

Requisitos de Admisión

Documentación indispensable para formalizar la inscripción:

  • Documento de Identidad Copia simple de DNI, Carné de Extranjería o Pasaporte vigente.
  • Condición Continental (si aplica) Código de estudiante o carné universitario para el 20% de descuento.
  • Examen de Ubicación Solo para alumnos que deseen convalidar niveles superiores a Básico 1.
  • Comprobante de Pago Constancia de la primera cuota o pago total del nivel.
